# Python Data Structures

Comprehensive Python programs covering fundamental built-in data structures and algorithms.

## 📌 Topics Covered
- **Lists**: Indexing, slicing, dynamic resizing, list comprehension, nested lists
- **Dictionaries**: Key-value mappings, hashing, record lookups, nested dictionaries
- **Tuples**: Immutability, packing/unpacking
- **In-Memory CRUD**: Student and account record management systems using pure data structures

## 🚀 Usage
```bash
python filename.py
```
